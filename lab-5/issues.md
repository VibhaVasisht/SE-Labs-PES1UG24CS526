# Documented Issues 

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| Mutable default argument (W0102 dangerous-default-value) | Bug (High) | 11–13 | `settings={}` is created once and shared by every call to `addDevice`. All four devices end up pointing at the same dict, so when `setTemperature` sets the thermostat to 30, the light, fan and TV also show `{"temperature": 30}` (visible in the output and in `home_state.json`). | Default to `settings=None` and create a new dict inside the function: `settings = {} if settings is None else dict(settings)`. |
| Shell command injection (Bandit B602 `shell=True`) | Security (High) | 51 | `subprocess.call("bash scenes/" + sceneScript, shell=True)` passes caller input to a shell, so a value like `x; rm -rf ~` runs arbitrary commands (CWE-78). | Remove the unused helper, or call `subprocess.run(["bash", path], check=True)` without `shell=True` after checking that the script name is a plain filename inside `scenes/`. |
| Binding to all interfaces (Bandit B104) | Security (Medium) | 4 | `HUB_HOST = "0.0.0.0"` exposes the hub on every network interface, including public ones (CWE-605). | Default to `"127.0.0.1"` and let the host be set from configuration or an environment variable when wider access is needed. |
| Missing-device crash in `setTemperature` (not flagged by tools) | Bug (Medium) | 23–24 | `devices[deviceName]` raises `KeyError` for an unknown device, unlike `toggleDevice`, which handles that case. | Check `if deviceName not in devices`, print a message and return `False`. |
| Inconsistent return statements (R1710) | Bug (Medium) | 16–20 | `toggleDevice` returns a bool when the device is found but implicitly returns `None` when it isn't, which callers can confuse with "off". | Add an explicit `return None` (or raise/return `False`) on the not-found path so every path returns a value. |
| Open without encoding (W1514 unspecified-encoding) | Reliability (Medium) | 41 | `open(fileName, "w")` uses the platform's default encoding, so the saved JSON can differ between machines. | Use `open(file_name, "w", encoding="utf-8")`. |
| Hardcoded password (Bandit B105) | Security (Low) | 7 | `HUB_PASSWORD = "smarthome-demo"` is stored in source code, which is committed to version control (CWE-259). It is also never used. | Remove it, or read it from an environment variable (`os.environ.get("HUB_PASSWORD")`). |
| `subprocess` import (Bandit B404) | Security (Low) | 2 | Importing `subprocess` is flagged because it allows running external commands. It is only used by the risky `runScene` helper. | Remove the import together with `runScene`, or keep it only if the safe list-argument version is kept. |
| Non-snake_case names (C0103 invalid-name) | Style (Low) | 11, 16, 23, 32, 36, 40, 45, 49 | Functions (`addDevice`, `toggleDevice`, …) and arguments (`deviceName`, `fileName`, `sceneScript`) use camelCase, which breaks PEP 8. | Rename to snake_case (`add_device`, `device_name`, `file_name`, …) and update every call site. |
| Missing docstrings (C0114, C0116) | Style (Low) | 1, 11, 16, 23, 32, 36, 40, 45, 49, 54 | The module and all functions lack docstrings. | Add a module docstring and a one-line docstring to each function. |
| PEP 8 formatting (Flake8 E203, E302, E261, E501) | Style (Low) | 6, 40, 66, 68 | Space before `:` in the dict, only one blank line before `saveState`, one space before an inline comment, and a line 80 characters long. | Remove the extra space, add a second blank line, use two spaces before `#`, and split the long line. |
